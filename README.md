# SKELAR Recruitment Tools

Один сайт з двома інструментами:
- **Конструктор відмов** — генерує текст відмови кандидату (з опційною AI-персоналізацією).
- **Асистент для НМ** — чат-бот, який відповідає наймаючим менеджерам на питання про процес найму на основі внутрішньої бази знань SKELAR (`kb.txt`).

API-ключ Anthropic зберігається **тільки на сервері** (в змінній середовища), тому людям, яким ти пошериш лінк, нічого вводити не треба — просто відкривають сайт і користуються.

---

## Як задеплоїти на Railway (безкоштовно, ~10 хвилин)

### 1. Заведи GitHub-репозиторій
1. Створи новий репозиторій на [github.com](https://github.com/new) (наприклад `skelar-hm-tools`).
2. Заливай туди весь вміст цієй папки (`server.js`, `package.json`, `kb.txt`, `public/`, `.gitignore` тощо).
   - Якщо не користувалась git раніше — найпростіше через GitHub Desktop: відкрий папку → "Publish repository".

### 2. Створи проєкт на Railway
1. Зайди на [railway.com](https://railway.com) → увійди через GitHub.
2. **New Project → Deploy from GitHub repo** → обери свій репозиторій `skelar-hm-tools`.
3. Railway сам розпізнає, що це Node.js-проєкт (по `package.json`), і почне білдити.

### 3. Додай API-ключ
1. У проєкті відкрий сервіс → вкладка **Variables**.
2. Додай змінну:
   - `ANTHROPIC_API_KEY` = твій ключ з [console.anthropic.com](https://console.anthropic.com) (Settings → API Keys).
3. Натисни **Deploy**, щоб застосувати зміни.

### 4. Отримай публічне посилання
1. Відкрий **Settings → Networking → Generate Domain**.
2. Отримаєш лінк типу `https://skelar-hm-tools-production.up.railway.app` — це і є посилання, яке можна шерити всім.

Готово 🎉 Кожен, хто відкриє лінк, побачить сайт і зможе користуватись обома інструментами — без жодного налаштування зі свого боку.

## Оновлення бази знань асистента

Асистент відповідає на основі файлу `kb.txt` в корені проєкту. Якщо оновиш FAQ у Notion:
1. Онови `kb.txt` (можеш попросити мене перегенерувати його з актуальних Notion-сторінок).
2. Заливай оновлений файл в GitHub — Railway автоматично передеплоїть сервіс.

## Локальний запуск (для перевірки перед деплоєм)
```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```
Відкрий `http://localhost:3000`.
